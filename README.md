# 避障比赛地图仿真环境

一辆小车（绿色圆）在比赛地图上行驶：从出发区出发，按设定顺序绕过禁止通行区与障碍物
依次到达各个目标区域，最后回到出发区。

## 运行

```
python map_sim.py
```

或双击 `run.bat`（无控制台窗口）。

只依赖 Python 标准库（tkinter），无需安装任何第三方包。

## 比赛流程

```
① 选择出发点（点击一个蓝色正方形，另一个蓝格从此变成普通路径）
        ↓
② 放置障碍物（随机 1~2 个，或自己点格子手动摆）
        ↓
③ 勾选本次要到达的目标区域，并确定访问顺序
        ↓
④ 点“③ 开始仿真” → 自动按顺序跑完所有目标，最后回到出发点 → 弹出成绩总结
```

> 与旧版（v1.0.x）不同：不再“跑一段再点下一个目标”，而是**开跑前一次性设定好目标**，
> 点一次按钮就把整场仿真跑完。

## 地图解析结果

程序直接沿用 `map.jpg` 实测的黑线位置还原格子比例，得到 **5 行 x 5 列** 的地图：

```
        c1    c2    c3    c4    c5
  r1    .     .    红     .    蓝1      ← 蓝色 = 出发点1（比赛随机二选一）
  r2    .    黄     .    黄     .       ← 黄色 = 禁止通行区域
  r3    白2   .     .     .     橙
  r4    .    黄     .    黄     .
  r5    .     .    白1    .    蓝2
```

| 区域 | 格子 | 含义 |
| --- | --- | --- |
| 蓝色正方形 | r1c5、r5c5 | 小车出发点，比赛时随机选一个（另一个视为普通路径） |
| 黄色区域 | r2c2、r2c4、r4c2、r4c4 | 禁止通行，不可进入 |
| 红色区域 | r1c3 | **目标区域** |
| 橙色区域 | r3c5 | **目标区域** |
| 白色区域1 | r5c3 | **目标区域** |
| 白色区域2 | r3c1 | **目标区域** |

坐标写法 `r行c列`，行从上往下、列从左往右，均为 1..5。
四个目标区域：红色区域 r1c3、橙色区域 r3c5、白色区域1 r5c3、白色区域2 r3c1。

界面配色：可通行区域为灰色背景，白色目标区域**纯白**，橙色目标区域**橙色**，禁止通行黄色，
出发点蓝色，障碍物棕色，红色目标红色，小车为绿色圆，规划路径为深绿色实线，
设定目标阶段用黄色/橙色虚线一次性预览整条计划路径。

## 障碍物规则

* 数量：**1~2 个**（`Simulator.MAX_OBSTACLES = 2`）。
* 可放置位置：除**被选作出发点的那个蓝格**、**黄色禁行区**、**四个目标区域**以外的格子。
* **另一个蓝色出发点视为普通路径**，可以放障碍物（比赛规则：两个出发点随机二选一，
  没被选中的那个不再是出发点）。
* 放置后如果**任何一个目标区域变得不可达**，界面会用红框标出并禁用“下一步”，
  必须先调整障碍物——这与比赛“障碍物不能把目标堵死”的要求一致。

两种放置方式（都在主界面右侧面板）：

| 方式 | 说明 |
| --- | --- |
| 手动 | 左键点格子放置，再点一下取消；达到 2 个后不再接受新的 |
| 随机（模拟比赛） | 点“随机障碍物”按钮，随机 1~2 个；内部会自动重试，保证四个目标仍然可达 |

## 使用流程

1. 启动后弹出窗口，用鼠标点击一个**蓝色正方形**作为出发点（另一个蓝格从此视为普通路径）。
2. 主窗口进入“① 障碍物”：点格子手动摆，或点“随机障碍物”模拟比赛随机放置；
   放好后点“下一步”。
3. 进入“② 目标区域”：勾选本次要到达的目标区域（红色区域 / 橙色区域 / 白色区域1 / 白色区域2），
   **勾选先后就是访问顺序**，也可以点“▲ 提前 / ▼ 延后”调整。
   地图上会用黄色/橙色虚线一次性预览整条计划路径，面板显示预计总里程。
4. 点“③ 开始仿真”：小车自动按顺序逐段行驶（每段都是 BFS 最短路径、自动绕开禁行区与障碍物），
   每到一个目标区域就在记录里打一个 ★。
5. 四个目标都到过后，小车自动返回出发点；**停在出发点格心之后**结束本次仿真并弹出成绩总结：
   出发点、障碍物、计划访问顺序、累计行驶格数、小车最终位置、已到达 / 未到达目标。

其他操作：

* 鼠标移到黄色禁行格或障碍物上：光标变成禁止样式，状态栏提示不可通行。
* 仿真过程中不接受临时改目标；要改就点“重新开始”重走一遍。
* “速度”滑块可以调整动画快慢（0.4x ~ 3.0x），跑完整场仿真时很有用。
* “结束本次仿真”按钮可以中途立即结束（总结里会标明小车停在哪个格子）。

## 路径规划算法

**单段最短路** —— `map_sim.shortest_path(start, goal)` 使用 **BFS（广度优先搜索）**：

* 状态空间：5x5 = 25 个格子；邻接关系为上下左右 4 邻域。
* 不可通行的格子不进入搜索队列（`Cell.passable == False`），包括**黄色禁行区**与**障碍物**。
* 边权相同，BFS 首次到达终点即为最短路径，**以走过的格子数作为距离度量**，因此天然实现避障。
* 返回的路径包含起点与终点，例如 `出发点1 → r2c5 → 橙色区域 → r3c4 → r3c3 → r2c3 → 红色区域`，
  代表行驶 6 步、经过 7 个格子（因为 r1c4 放了障碍物，直路 3 格走不通）。

**整场计划** —— `map_sim.build_plan(start, targets)` 把
`出发点 → 目标1 → 目标2 → … → 出发点` 拼成一条完整路线：

* 每一段单独调用 BFS，保证**每一段都是最短路径**；
* 返回 `(segments, info)`：`segments` 是逐段的格子列表，`info` 含总步数、段数、错误信息；
* 顺序按用户勾选顺序（橙色也是目标，共 4 个可选）；
* 任何一段不可达（例如障碍物堵死出发区）都会返回 `error`，界面据此禁用“开始仿真”。

辅助函数：

| 函数 | 作用 |
| --- | --- |
| `obstacle_candidates(start_key)` | 列出可以放障碍物的格子 |
| `random_obstacles(start_key)` | 随机放 1~2 个障碍物，自动重试直到四个目标全部可达 |
| `reachable_goals(start_key)` | 返回（可达目标, 不可达目标），用于界面告警 |
| `build_plan(start, targets)` | 拼出整场仿真计划（含返回出发点） |
| `target_selection_text(targets)` | 把访问顺序写成「① 红色区域、② 橙色区域…」 |
| `place_obstacles(keys)` / `clear_obstacles()` | 直接摆放 / 清空障碍物 |

因为禁行格把地图切成多条竖直/水平通道，BFS 会自动选择绕行方式，例如没有障碍物时
`出发点1(r1c5) → 红色区域(r1c3)` 走第 1 行共 3 格；一旦 r1c4 被放上障碍物，
就会改成绕第 3 行过去，变成 7 格。加上这个绕行后，四目标全程由 20 步变成 24 步。

## 代码结构（`map_sim.py`）

| 部分 | 说明 |
| --- | --- |
| `X_BOUNDS` / `Y_BOUNDS` | 从 map.jpg 实测出的黑线像素坐标，保证格子比例与原图一致 |
| `Cell` / `build_grid()` | 25 个格子的颜色、类型、目标名称、障碍物状态 |
| `GOAL_INFO` / `DEFAULT_TARGETS` | 四个目标区域及其默认访问顺序 |
| `shortest_path()` | BFS 最短路径（自动绕开禁行区与障碍物） |
| `build_plan()` / `plan_text()` | 整场仿真计划与文字描述 |
| `random_obstacles()` 等 | 障碍物候选、随机放置、可达性检查 |
| `StartDialog` | 出发点选择弹窗（点击地图上的蓝色格子） |
| `Simulator` | 主窗口：三阶段流程（setup / targets / run）、画布绘制、勾选面板、自动连跑动画 |

常用可调参数（文件开头）：

```python
CELL_PX = 140        # 格子显示大小（像素），屏幕放不下时会自动缩小
MARGIN = 26          # 画布留白
CAR_R = 26           # 小车半径
STEP_SECONDS = 0.30  # 走一格的基础耗时（秒）
MAX_OBSTACLES = 2    # 障碍物数量上限（Simulator 类属性）
```

`cell_px_for_screen()` 会按屏幕分辨率自动缩格子，保证“地图 + 右侧面板”完整显示在屏幕内。

## 自检工具（`tools/`）

一键跑完全部自检：双击 `check.bat`（或依次执行下表前四个脚本）。

| 脚本 | 作用 |
| --- | --- |
| `python tools/verify_sim.py` | 地图定义 + 625 组起终点 BFS 交叉校验 + 障碍物规则/绕行/随机放置 + 行驶计划 `build_plan` 检查 |
| `python tools/smoke_gui.py` | 用真实 Tk 界面模拟点击，跑通“选起点 → 摆障碍 → 勾目标 → 自动连跑 → 结束”完整流程 |
| `python tools/check_draw.py` | 检查画布实际绘制的颜色、障碍物、计划预览虚线、小车最终位置 |
| `python tools/render_preview.py` | 生成整场仿真的效果图 `tools/shots/route_preview.png` |
| `python tools/verify_render.py` | 对效果图逐格像素校验，并从图里反推障碍物位置核对每段路径 |
| `python tools/verify_live.py` | 对真实屏幕截图 `tools/shots/live.png` 做标定后逐格校验（含计划预览虚线） |
| `python tools/auto_demo.py` | 无人值守演示：随机放障碍 → 勾四个目标 → 自动跑完整场并回到出发点 |
| `python tools/live_scene.py` | 把界面摆到“目标区域已勾选、显示计划预览”的状态供截图 |
| `tools/analyze_map.py` 等 | 当初解析 map.jpg 用的像素分析脚本 |
