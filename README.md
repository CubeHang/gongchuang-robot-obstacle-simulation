# 避障比赛地图仿真环境

一辆小车（绿色圆）在比赛地图上行驶，按最短路径绕过障碍物到达各个目标地点，最后回到出发点。

## 运行

```
python map_sim.py
```

或双击 `run.bat`（无控制台窗口）。

只依赖 Python 标准库（tkinter），无需安装任何第三方包。

## 比赛流程

```
① 选择出发点（点击一个蓝色正方形）
        ↓
② 放置障碍物（随机 1~2 个，或自己点格子手动摆）
        ↓
③ 点“开始仿真” → 路径规划 + 小车避障行驶
        ↓
④ 反复选择目标地点，最后点回出发点 → 结束，弹出成绩总结
```

## 地图解析结果

程序直接沿用 `map.jpg` 实测的黑线位置还原格子比例，得到 **5 行 x 5 列** 的地图：

```
        c1    c2    c3    c4    c5
  r1    .     .    红     .    蓝1      ← 蓝色 = 出发点1（比赛随机二选一）
  r2    .    黄     .    黄     .       ← 黄色 = 禁止通行区域
  r3    白2   .     .     .     橙
  r4    .    黄     .    黄     .
  r5    .     .    白1    .    蓝2      ← 白色区域1 / 白色区域2 / 红色区域 = 目标地点
```

| 区域 | 格子 | 含义 |
| --- | --- | --- |
| 蓝色正方形 | r1c5、r5c5 | 小车出发点，比赛时随机选一个 |
| 黄色区域 | r2c2、r2c4、r4c2、r4c4 | 禁止通行，不可进入 |
| 红色区域 | r1c3 | 目标地点 |
| 白色区域1 | r5c3 | 目标地点 |
| 白色区域2 | r3c1 | 目标地点 |
| 橙色格子 | r3c5 | 普通可通行格子，仅底色不同 |

坐标写法 `r行c列`，行从上往下、列从左往右，均为 1..5。
白色区域1 在**第 5 行第 3 列**，白色区域2 在**第 3 行第 1 列**，橙色格子在**第 3 行第 5 列**。

界面配色：可通行区域为灰色背景，两个白色目标区域为**纯白**，禁止通行黄色，出发点蓝色，
第 3 行第 5 列为**橙色**，障碍物棕色，红色目标红色，小车为绿色圆，规划路径为深绿色实线，
鼠标悬停时用黄色虚线预览最短路径。

## 障碍物规则

* 数量：**1~2 个**（`Simulator.MAX_OBSTACLES = 2`）。
* 可放置位置：除**被选作出发点的那个蓝格**、**黄色禁行区**、**三个目标地点**以外的格子。
* **另一个蓝色出发点视为普通路径**，可以放障碍物（比赛规则：两个出发点随机二选一，
  没被选中的那个不再是出发点）。
* 放置后如果**任何一个目标地点变得不可达**，界面会用红框标出并禁用“开始仿真”，
  必须先调整障碍物——这与比赛“障碍物不能把目标堵死”的要求一致。

两种放置方式（都在主界面右侧面板）：

| 方式 | 说明 |
| --- | --- |
| 手动 | 左键点格子放置，再点一下取消；达到 2 个后不再接受新的 |
| 随机（模拟比赛） | 点“随机障碍物”按钮，随机 1~2 个；内部会自动重试，保证三个目标仍然可达 |

## 使用流程

1. 启动后弹出窗口，用鼠标点击一个**蓝色正方形**作为出发点。
2. 主窗口进入“① 放置障碍物”：点格子手动摆，或点“随机障碍物”模拟比赛随机放置。
3. 点“② 开始仿真”进入仿真阶段；此时鼠标移到任意可通行格子上会实时显示
   **黄色预览最短路径（已绕开障碍物）**和**经过格数**。
4. 点击格子 → 小车以绿色圆的形式沿最短路径（深绿色实线）行驶到该格子。
5. 到达后可以继续点下一个目标地点，如此来回循环。
6. 点击**出发点所在的格子**（或按“结束本次仿真”按钮）结束本次仿真，弹出成绩总结：
   出发点、障碍物、累计行驶格数、已到达 / 未到达的目标地点。

其他操作：

* 鼠标移到黄色禁行格或障碍物上：光标变成禁止样式，状态栏提示不可通行，点击无效。
* 行驶过程中不接受新的选择，避免插队。
* “速度”滑块可以调整动画快慢（0.4x ~ 3.0x）。
* “重新开始”按钮重新走一遍“选出发点 → 摆障碍物 → 仿真”。

## 路径规划算法

`map_sim.shortest_path(start, goal)` 使用 **BFS（广度优先搜索）**：

* 状态空间：5x5 = 25 个格子；邻接关系为上下左右 4 邻域。
* 不可通行的格子不进入搜索队列（`Cell.passable == False`），包括**黄色禁行区**与**障碍物**。
* 边权相同，BFS 首次到达终点即为最短路径，**以走过的格子数作为距离度量**，因此天然实现避障。
* 返回的路径包含起点与终点，例如 `出发点1 → r2c5 → r3c5 → r3c4 → r3c3 → r2c3 → 红色区域`，
  代表行驶 6 步、经过 7 个格子（因为 r1c4 放了障碍物，直路 3 格走不通）。

辅助函数：

| 函数 | 作用 |
| --- | --- |
| `obstacle_candidates(start_key)` | 列出可以放障碍物的格子 |
| `random_obstacles(start_key)` | 随机放 1~2 个障碍物，自动重试直到目标全部可达 |
| `reachable_goals(start_key)` | 返回（可达目标, 不可达目标），用于界面告警 |
| `place_obstacles(keys)` / `clear_obstacles()` | 直接摆放 / 清空障碍物 |

因为禁行格把地图切成多条竖直/水平通道，BFS 会自动选择绕行方式，例如没有障碍物时
`出发点1(r1c5) → 红色区域(r1c3)` 走第 1 行共 3 格；一旦 r1c4 被放上障碍物，
就会改成绕第 3 行过去，变成 7 格。

## 代码结构（`map_sim.py`）

| 部分 | 说明 |
| --- | --- |
| `X_BOUNDS` / `Y_BOUNDS` | 从 map.jpg 实测出的黑线像素坐标，保证格子比例与原图一致 |
| `Cell` / `build_grid()` | 25 个格子的颜色、类型、目标名称、障碍物状态 |
| `shortest_path()` | BFS 最短路径（自动绕开禁行区与障碍物） |
| `random_obstacles()` 等 | 障碍物候选、随机放置、可达性检查 |
| `StartDialog` | 出发点选择弹窗（点击地图上的蓝色格子） |
| `Simulator` | 主窗口：阶段流程（setup / select / move）、画布绘制、鼠标交互、路径预览、小车动画 |

常用可调参数（文件开头）：

```python
CELL_PX = 140        # 格子显示大小（像素），屏幕放不下时会自动缩小
MARGIN = 26          # 画布留白
CAR_R = 26           # 小车半径
STEP_SECONDS = 0.30  # 走一格的基础耗时（秒）
MAX_OBSTACLES = 2    # 障碍物数量上限（Simulator 类属性）
```

`cell_px_for_screen()` 会按屏幕分辨率自动缩格子，保证“地图 + 右侧面板”完整显示在屏幕内。

## 自检工具（`tools/`）

一键跑完全部自检：双击 `check.bat`（或依次执行下表前四个脚本）。

| 脚本 | 作用 |
| --- | --- |
| `python tools/verify_sim.py` | 地图定义核对 + 625 组起终点 BFS 全量交叉校验 + 障碍物规则/绕行/随机放置检查 |
| `python tools/smoke_gui.py` | 用真实 Tk 界面模拟点击与动画，跑通“选起点 → 摆障碍 → 避障行驶 → 结束”完整流程 |
| `python tools/check_draw.py` | 检查画布实际绘制的颜色、障碍物、小车位置、预览路径顶点 |
| `python tools/render_preview.py` | 生成带障碍物的路径效果图 `tools/shots/route_preview.png` |
| `python tools/verify_render.py` | 对效果图逐格像素校验，并从图里反推障碍物位置核对路径 |
| `python tools/verify_live.py` | 对真实屏幕截图 `tools/shots/live.png` 做标定后逐格校验 |
| `python tools/auto_demo.py` | 无人值守演示：随机放障碍 → 开始仿真 → 依次跑目标 → 回到出发点 |
| `tools/analyze_map.py` 等 | 当初解析 map.jpg 用的像素分析脚本 |
