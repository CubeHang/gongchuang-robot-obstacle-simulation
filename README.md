# 避障比赛地图仿真环境

一辆小车（绿色圆）在比赛地图上行驶，按最短路径到达各个目标地点，最后回到出发点。

## 运行

```
python map_sim.py
```

或双击 `run.bat`（无控制台窗口）。

只依赖 Python 标准库（tkinter），无需安装任何第三方包。

## 地图解析结果

程序直接沿用 `map.jpg` 实测的黑线位置还原格子比例，得到 **5 行 x 5 列** 的地图：

```
        c1    c2    c3    c4    c5
  r1    .     .    红     .    蓝1      ← 蓝色 = 出发点1（比赛随机二选一）
  r2    .    黄     .    黄     .       ← 黄色 = 禁止通行区域
  r3    白2   .     .     .     .
  r4    .    黄     .    黄     .
  r5    .     .    白1    .    蓝2      ← 白色区域1 / 白色区域2 / 红色区域 = 目标地点
```

| 区域 | 格子 | 含义 |
| --- | --- | --- |
| 蓝色正方形 | r1c5、r5c5 | 小车出发点，比赛时随机选一个 |
| 黄色区域 | r2c2、r2c4、r4c2、r4c4 | 禁止通行，不可进入 |
| 红色区域 | r1c3 | 目标地点 |
| 白色区域1 | r5c3 | 目标地点 |
| 白色区域2 | r3c1 | 目标地点 |

坐标写法 `r行c列`，行从上往下、列从左往右，均为 1..5。
白色区域1 在**第 5 行第 3 列**，白色区域2 在**第 3 行第 1 列**。

界面配色：可通行区域为灰色背景，两个白色目标区域为**纯白**，禁止通行黄色，出发点蓝色，
红色目标红色，小车为绿色圆，规划路径为深绿色实线，鼠标悬停时用黄色虚线预览最短路径。

## 使用流程

1. 启动后弹出窗口，用鼠标点击一个**蓝色正方形**作为出发点。
2. 主窗口出现，鼠标移到任意可通行格子上会实时显示**黄色预览最短路径**和**经过格数**。
3. 点击格子 → 小车以绿色圆的形式沿最短路径（深绿色实线）行驶到该格子。
4. 到达后可以继续点下一个目标地点，如此来回循环。
5. 点击**出发点所在的格子**（或按“结束本次仿真”按钮）结束本次仿真，弹出成绩总结：
   出发点、累计行驶格数、已到达 / 未到达的目标地点。

其他操作：

* 鼠标移到黄色格子：光标变成禁止样式，状态栏提示“黄色区域禁止通行，不能作为目标”，点击无效。
* 行驶过程中不接受新的选择，避免插队。
* “速度”滑块可以调整动画快慢（0.4x ~ 3.0x）。
* “重新选择出发点”按钮重新开始一次仿真。

## 路径规划算法

`map_sim.shortest_path(start, goal)` 使用 **BFS（广度优先搜索）**：

* 状态空间：5x5 = 25 个格子；邻接关系为上下左右 4 邻域。
* 黄色禁止通行格子不进入搜索队列（`Cell.passable == False`）。
* 边权相同，BFS 首次到达终点即为最短路径，**以走过的格子数作为距离度量**。
* 返回的路径包含起点与终点，例如 `出发点1 → r2c5 → r3c5 → r4c5 → 出发点2 → r5c4 → 白色区域2 → r5c2 → 白色区域1`，代表行驶 8 步、经过 9 个格子。

因为禁止通行格把地图切成多条竖直/水平通道，BFS 会自动选择绕行方式，例如
`出发点1(r1c5) → 红色区域(r1c3)` 走第 1 行共 3 格；
`红色区域(r1c3) → 白色区域1(r5c1)` 走第 3 列下去再折向左，共 7 格；
绕开 (2,2)、(4,2) 两个禁行格。

## 代码结构（`map_sim.py`）

| 部分 | 说明 |
| --- | --- |
| `X_BOUNDS` / `Y_BOUNDS` | 从 map.jpg 实测出的黑线像素坐标，保证格子比例与原图一致 |
| `Cell` / `build_grid()` | 25 个格子的颜色、类型、目标地点名称 |
| `shortest_path()` | BFS 最短路径 |
| `StartDialog` | 出发点选择弹窗（点击地图上的蓝色格子） |
| `Simulator` | 主窗口：画布绘制、鼠标交互、路径预览、小车动画、行驶记录 |

常用可调参数（文件开头）：

```python
CELL_PX = 140        # 格子显示大小（像素），屏幕放不下时会自动缩小
MARGIN = 26          # 画布留白
CAR_R = 26           # 小车半径
STEP_SECONDS = 0.30  # 走一格的基础耗时（秒）
```

`cell_px_for_screen()` 会按屏幕分辨率自动缩格子，保证“地图 + 右侧面板”完整显示在屏幕内。

## 自检工具（`tools/`）

一键跑完全部自检：双击 `check.bat`（或依次执行下表前四个脚本）。

| 脚本 | 作用 |
| --- | --- |
| `python tools/verify_sim.py` | 地图定义核对 + 625 组起终点 BFS 全量交叉校验（含禁行格拒绝） |
| `python tools/smoke_gui.py` | 用真实 Tk 界面模拟点击与动画，跑通完整流程 |
| `python tools/check_draw.py` | 检查画布实际绘制的颜色、小车位置、预览路径顶点 |
| `python tools/render_preview.py` | 生成路径效果图 `tools/shots/route_preview.png` |
| `python tools/verify_render.py` | 对效果图做逐格像素校验 |
| `python tools/verify_live.py` | 对真实屏幕截图 `tools/shots/live.png` 做标定后逐格校验 |
| `python tools/auto_demo.py` | 无人值守演示：自动选出发点、依次跑目标、最后回到出发点 |
| `tools/analyze_map.py` 等 | 当初解析 map.jpg 用的像素分析脚本 |
